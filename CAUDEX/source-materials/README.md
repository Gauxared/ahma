Эта папка хранит исходные материалы, присланные коллегой/продуктовой командой, которые использовались при уточнении CAUDEX.

Важно: содержимое `source-materials/` сохраняется как **source evidence**, а не как нормативная версия архитектуры. Если исходный материал противоречит решениям CAUDEX, приоритет и комментарий фиксируются в аналитических документах CAUDEX.
