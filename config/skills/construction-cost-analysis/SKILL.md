# Анализ себестоимости строительных проектов

## Что делает навык

Превращает разрозненные сметные документы строительного проекта (PDF локальных смет, обоснование НМЦК, ВОР) в **единый аналитический файл** с финансовым результатом подрядчика. Подход проверен на дорожном капремонте в Республике Дагестан (10 км, 12 ЛСР, 3 385 позиций, НМЦК 411 млн руб) — точность сходимости с шапками ЛСР 100 % (копейка в копейку).

**Ключевая ценность:** разделение проекта на два независимых слоя:
- **Материалы** (ФССЦ-позиции) — сравнение со конкретными прайсами поставщиков в регионе
- **Работы** (расценки ФЕР/ФЕРр/ТЕР) — сравнение через коэффициент рыночности по группам кодов

Сумма дельт по двум слоям = дополнительная прибыль подрядчика сверх плановой маржи в сметных НР+СП.

## Главный workflow (7 этапов)

Этапы выполняются последовательно, но в большинстве случаев пользователь приходит **не с самого начала** — может прислать готовые исходники или, наоборот, готовый Excel и попросить расширить аналитику. Подстраивайся под точку входа.

### Этап 1. Инвентаризация исходников

Проверь, какие документы есть у пользователя. Типичный пакет проекта:

| Документ | Что содержит | Обязательность |
|---|---|---|
| **Том локальных смет (ЛСР), PDF** | Детальные расчёты по 5-20 ЛСР: коды ФЕР, объёмы, базис, индекс, текущая стоимость | Критический. Без него — никак |
| **Обоснование НМЦК, RTF/PDF/Excel** | Индексы инфляции к целевой дате, агрегация по главам, итоговая НМЦК | Критический для индексов |
| **Смета контракта (укрупнённая), XLSX** | Тех. элементы и подпозиции в свёрнутом виде | Желательно — для сверки |
| **Ведомость объёмов работ (ВОР), PDF** | Физические объёмы по тех. элементам | Желательно — для контроля |
| **Проект контракта, DOCX** | Сроки, авансы, штрафы, контролирующие организации | Опционально |

Прежде чем парсить — **спроси у пользователя**, какая у него цель: только Excel с дельтой? Аналитическая справка тоже? На какую дату пересчитывать?

### Этап 2. Парсинг локальных смет из PDF

Это самая трудоёмкая часть. Детальная методика — в `references/pdf-parsing.md`. Прочти этот файл перед началом.

Краткий принцип:
1. `pdftotext -layout` — конвертация PDF в текст с сохранением колоночной структуры
2. Regex по типам строк: ФЕР/ФЕРр/ТЕР (работы), ФССЦ (материалы), ФССЦпг (перевозки), "Итого по позиции", "ВСЕГО по смете"
3. Извлечение шапок ЛСР для контроля сходимости
4. **Обязательная проверка:** сумма всех "ВСЕГО по смете" должна совпасть с шапками ЛСР с точностью до копеек

Результат — JSON со всеми позициями + метаданные ЛСР. Это твой "источник истины", который ты сохраняешь и затем используешь во всех последующих этапах.

### Этап 3. Извлечение индексов инфляции

Из обоснования НМЦК извлекаются:
- **Индекс перевода базис → текущая ЛСР** (обычно 4 кв. 2000 г. → 4 кв. 2023 г., значение ~11.2-11.8)
- **Прогнозный индекс к целевой дате** (помесячный, ~1.004 в месяц для дорожного строительства)
- **Совокупный индекс к целевой дате** = индекс перевода × прогнозный

Подробнее — `references/indices-and-base.md`.

**Целевая дата** — критический параметр. По умолчанию бери "ближайший квартал после текущей даты". Если пользователь не указал — спроси.

### Этап 4. Сборка базового Excel-файла

Стандартная структура — **11 листов** в определённом порядке. Детальные шаблоны — `references/excel-structure.md` и `assets/excel_template_structure.md`.

Краткий список листов:
1. **README** — навигация, ключевые цифры, инструкция как менять
2. **Объект** — реквизиты заказчика и подрядчика, сроки
3. **Параметры_индексы** — управляющий лист (изменение целевой даты пересчитывает весь файл)
4. **Смета_контракта** — укрупнённая (если приложение есть)
5. **Свод_по_главам** — итоги по главам ССР
6. **Себестоимость_итог** ⭐ — главный лист: расчёт «под ключ» + блок коррекции по рынку + финансовый результат
7. **ВОР_укрупненный** — физические объёмы
8. **Свод_ЛСР** — итоги по локальным сметам
9. **Ключевые_ресурсы** ⭐ — материалы с рыночными ценами
10. **Ключевые_работы** ⭐ — работы с коэф. рыночности
11. **Все_позиции** ⭐ — все строки из ЛСР с автофильтром

После сборки — **сверь итог** с шапками ЛСР. Если расхождение больше 1 руб — ищи ошибку в парсере, не двигайся дальше.

### Этап 5. Анализ рыночных цен материалов

Для каждого ключевого материала из ЛСР — найди рыночную цену в регионе реализации проекта.

**Стратегия поиска:**
1. Идентифицируй регион (область/республика, город, район)
2. Через `web_search` найди прайсы локальных поставщиков
3. Для каждой категории материалов — отдельный поиск:
   - Бетон, ЖБИ: "[материал] цена куб [город]"
   - Песок, ПГС, щебень: "[материал] цена м3 карьер [регион]"
   - Битум, асфальтобетон: "[материал] цена тонна [регион] завод 2025-2026"
   - Металл, арматура: "[материал] цена тонна [регион] прокат"
4. Используй контакты конкретных компаний из результатов (например, "Гамма-Бетон Махачкала", "Талгиспецстрой") — это даёт верификацию данных

**Региональные особенности учитывай:** в горных регионах (Дагестан, Кавказ, Алтай) ПГС/щебень дешевле сметы; в нефтяных регионах битум ближе к смете; в северных регионах металл дороже из-за логистики.

Подробный справочник источников — `references/market-prices-russia.md`.

### Этап 6. Применение коэффициентов рыночности работ

Для **работ** прямые "прайсы" не работают — используется **коэффициент рыночности** (отношение реальной стоимости к сметной).

1. Все работы группируются по префиксу кода ФЕР (`27-04`, `01-02`, `03-02` и т.д.)
2. Для каждой группы применяется типичный коэффициент:
   - 0,70-0,75 — озеленение, рекультивация (высокая маржа)
   - 0,78-0,82 — гидроизоляция, бетонные работы трубы, демонтаж
   - 0,82-0,85 — земляные работы (своя техника), обустройство
   - 0,85-0,88 — БВР, ремонтные работы
   - 0,88-0,92 — дорожная одежда (асфальт) — конкурентный рынок

Полная таблица коэффициентов — `assets/coefficient_defaults.json` и `references/work-rates-coefficients.md`.

3. Через `VLOOKUP` по коду ФЕР дельта проставляется на каждой строке "Работа" в листе "Все_позиции"

### Этап 7. Финансовый результат + аналитическая справка

На листе **Себестоимость_итог** собирается итог:
- Сметная стоимость «под ключ» (по обоснованию НМЦК + затраты заказчика)
- Прибыль на материалах (дельта со рынком)
- Прибыль на работах (дельта через коэф.)
- **Общая дополнительная прибыль** (сумма двух)
- Маржинальность (% от НМЦК)

Если пользователь просит аналитическую справку — генерируй Word-документ через `docx-js` по шаблону `references/word-report.md`. Стандартная структура: титул → резюме → о проекте → как читать Excel → финрезультат → источники → методология → погрешности → выводы.

## Принципы и правила

### Сходимость — это закон

После каждого этапа парсинга и сборки проверяй итоговые суммы:
- Сумма ЛСР = шапки ЛСР (точность 1 руб)
- Сумма по главам = НМЦК подрядчика без НДС
- Дельта по работам в "Все_позиции" = дельта в "Ключевые_работы" (0 руб разница)
- Сметная стоимость материалов в "Себестоимость_итог" = G114 в "Ключевые_ресурсы"

Если расхождение — это сигнал стоп, разбирайся.

### Нет двойного счёта

Материалы (ФССЦ-подпозиции) и работы (ФЕР-расценки) — два **независимых** слоя:
- Дельта материалов = разница сметных и рыночных цен **только по ФССЦ-подпозициям**
- Дельта работ = (сметная стоимость работы × (1 − коэф)) **без учёта подпозиций**

Материалы в составе самой расценки ФЕР (М) уже включены в "Работа" и учитываются через коэф. рыночности — НЕ выделяй их отдельно как ФССЦ.

### Артефакты парсинга — норма

В наименованиях позиций из PDF часто остаются "хвосты" из соседних колонок (числа в конце наименования). Это не ошибка — это особенность колоночной структуры PDF. Для агрегации материалов используй обрезку наименования до значимой части. Для работ матчинг делай по коду ФЕР, а не по наименованию (надёжнее).

В колонке "Кол-во" в "Все_позиции" для подпозиций ФССЦ может быть не реальный объём, а коэффициент — **не используй** её для расчёта "qty × цена". Используй стоимость целиком (колонки O и P).

### Базисный, текущий, целевой — три уровня цен

Российские сметы имеют трёхуровневую структуру цен. Запомни и фиксируй в файле:
1. **Базисный** — обычно 4 кв. 2000 г. (ФЕР-2001). Это сметная база.
2. **Текущий в ЛСР** — обычно 4 кв. 2023 г. через индекс перевода ~11.2-11.8 от Минстроя.
3. **Целевой расчёта** — на нужный квартал через прогнозный индекс Минэкономразвития.

Все формулы пересчёта Excel должны идти через одну центральную ячейку (обычно `Параметры_индексы!B21` = совокупный индекс). Изменение этой ячейки = пересчёт всего файла.

### Деликатность в формулировках

Расчёт «прибыль подрядчика 2,8%» — это **дополнительная прибыль** сверх НР+СП в смете. Не путай:
- Сметная маржа (НР 147% от ОТ + СП 134% от ОТ + резерв 3%) — заложена в стоимость работ
- Дополнительная маржа из дельты — это то, что считает наш скилл

Итоговая ожидаемая прибыль подрядчика на госконтрактах обычно 5-10% от НМЦК. Это уточняй в аналитической справке.

## Типичная точка входа в работу

Чаще всего пользователь приходит с одним из таких запросов:

**«Вот PDF локальных смет, посчитай себестоимость объекта на 2026 год»** — выполняй весь workflow с этапа 1.

**«Это проект в [регион]. Найди реальные рыночные цены материалов и покажи дельту»** — этап 5 (нужен готовый Excel с этапа 4).

**«Найди рыночные цены и на работы тоже»** — этап 6.

**«Сделай аналитическую справку»** — этап 7 (нужен Excel с полным финансовым результатом).

**«Поменяй дату расчёта на [квартал]»** — измени B18 на листе Параметры_индексы, запусти пересчёт формул.

В каждом случае: понимай, на каком этапе находишься, прочитай соответствующий reference, выполняй. Не лезь в этап 5 раньше этапа 4 — без чистой сметной базы ничего не сойдётся.

## Что сделать **в самом конце** работы

1. Сохрани файлы в `/mnt/user-data/outputs/`
2. Используй `present_files` чтобы передать пользователю
3. Покажи финальные цифры (прибыль/убыток, маржинальность, ключевые риски) текстом в чате
4. Предложи следующие шаги: уточнить рыночные цены, изменить коэф. работ, поменять дату, сделать аналитическую справку
