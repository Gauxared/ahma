## Лист 4: Смета_контракта

```

[Шапка таблицы]

  A: №
```

## Лист 6: Себестоимость_итог ⭐

Главный аналитический лист. Структура «сверху вниз»:

### Блок 1: Прямые работы по ЛСР

```
Шапка (row 5):
  A: №    B: Статья затрат    C: Источник
  D: Сумма 4 кв. 2023, руб    E: Сумма 2 кв. 2026, руб

Row 6-17: по одной строке на каждый ЛСР
  Формулы: 
    D{r} = 'Свод_ЛСР'!G{соответствующая_строка}
    E{r} = 'Свод_ЛСР'!H{соответствующая_строка}

Row 18: ИТОГО прямые работы по ЛСР  [F_BOLD, FILL_TOTAL]
  D18 = SUM(D6:D17)
  E18 = SUM(E6:E17)
```

### Блок 2: Прочие позиции

```
Row 20-23: ВЗиС, удорожание зимой, диагностика, рабочая документация
  Каждая позиция:
    D{r}: значение в 4 кв. 2023
    E{r}: =D{r} * 'Параметры_индексы'!$B$21

Row 25: ИТОГО затраты подрядчика (до непредвиденных)
  D25 = D18 + SUM(D20:D23)
  E25 = E18 + SUM(E20:E23)
```

### Блок 3: Непредвиденные и НДС

```
Row 26: Резерв 3%
  D26 = D25 * 0.03
  E26 = E25 * 0.03

Row 27: ИТОГО без НДС  [F_BOLD, FILL_TOTAL]
  D27 = D25 + D26
  E27 = E25 + E26

Row 28: НДС 22%
  D28 = D27 * 0.22
  E28 = E27 * 0.22

Row 29: ИТОГО НМЦК подрядчика с НДС  [F_BOLD, FILL_TOTAL]
  D29 = D27 + D28
  E29 = E27 + E28
```

### Блок 4: Затраты заказчика

```
Row 31: Заголовок "ЗАТРАТЫ ЗАКАЗЧИКА"  [F_SUBTITLE, FILL_GROUP, merged]

Row 32-35: ПИР, госэкспертиза, стройконтроль, авторский надзор

Row 37: Итого затраты заказчика без НДС  [F_BOLD, FILL_TOTAL]
Row 38: НДС 22% (только на стройконтроль и АН)
Row 39: Итого затраты заказчика с НДС  [F_BOLD, FILL_TOTAL]
```

### Блок 5: Главный итог

```
Row 41: ✅ СМЕТНАЯ СТОИМОСТЬ ОБЪЕКТА «ПОД КЛЮЧ»  [BIG, FILL_RED, color=white]
  D41 = D29 + D39
  E41 = E29 + E39
  height=30
```

### Блок 6: КОРРЕКЦИЯ ПО РЫНКУ — Материалы

```
Row 44: Заголовок "📊 АНАЛИЗ РЫНОЧНОЙ СТОИМОСТИ"  [BIG, FILL_HEADER_DELTA]

Row 46: Заголовок "🟢 МАТЕРИАЛЫ"  [F_BOLD, FILL_GREEN]

Row 47: Сметная стоимость материалов (где есть рынок) на 2 кв. 2026
  E47 = 'Ключевые_ресурсы'!G114

Row 48: Рыночная стоимость материалов на 2 кв. 2026
  E48 = 'Ключевые_ресурсы'!I114

Row 49: 📈 ДЕЛЬТА по материалам (заработок)  [FILL_POSITIVE, F_POSITIVE]
  E49 = 'Ключевые_ресурсы'!J114
```

### Блок 7: КОРРЕКЦИЯ ПО РЫНКУ — Работы

```
Row 51: Заголовок "🟢 РАБОТЫ"  [F_BOLD, FILL_PURPLE]

Row 52: Сметная стоимость работ на 2 кв. 2026
  E52 = SUMIFS('Ключевые_работы'!F6:F30, 'Ключевые_работы'!A6:A30, ">0")

Row 53: Рыночная стоимость работ на 2 кв. 2026
  E53 = SUMIFS('Ключевые_работы'!H6:H30, 'Ключевые_работы'!A6:A30, ">0")

Row 54: 📈 ДЕЛЬТА по работам (заработок)  [FILL_POSITIVE, F_POSITIVE]
  E54 = SUMIFS('Ключевые_работы'!I6:I30, 'Ключевые_работы'!A6:A30, ">0")
```

### Блок 8: Финансовый результат

```
Row 56: Заголовок "💎 ФИНАНСОВЫЙ РЕЗУЛЬТАТ ПРОЕКТА"  [BIG, FILL_BLUE]

Row 57: ИТОГО прибыль на материалах
  E57 = E49

Row 58: ИТОГО прибыль на работах
  E58 = E54

Row 59: 💰 ОБЩАЯ ПРИБЫЛЬ ПОДРЯДЧИКА  [BIG, FILL_GREEN, F_BIG_POSITIVE]
  E59 = E57 + E58

Row 60: 📊 Маржинальность (% от НМЦК)
  E60 = E59 / E29
  number_format = '0.0%'

Row 62: ✅ ФАКТИЧЕСКАЯ СЕБЕСТОИМОСТЬ ПОДРЯДЧИКА  [BIG, FILL_RED]
  E62 = E41 - E59
```

### Блок 9: Ключевые факторы

```
Row 64: Заголовок "⚠️ КЛЮЧЕВЫЕ ФАКТОРЫ И РИСКИ"  [F_SUBTITLE, FILL_GROUP]

Row 65-75: Топ-5 убытков + топ-5 заработков
  Колонка B: название
  Колонка C: пояснение
  Колонка E: сумма
  Покраска: положит. → FILL_POSITIVE, отриц. → FILL_NEGATIVE
```

## Лист 10: Ключевые_работы ⭐

```
Шапка (row 5):
  A: №    B: Префикс кода ФЕР    C: Группа работ
  D: Кол-во расценок
  E: Сметная стоимость 4 кв. 2023
  F: Сметная стоимость 2 кв. 2026  = E * 'Параметры_индексы'!$B$21
  G: КОЭФФИЦИЕНТ РЫНОЧНОСТИ  [FILL_INPUT — редактируется]
  H: Рыночная стоимость = F * G
  I: ДЕЛЬТА = F - H  [покраска зелёная]

Группы сортируются по убыванию сметной стоимости.

Итоговая строка:
  E[итог] = SUM(E6:E[max-1])
  F[итог] = SUM(F6:F[max-1])
  H[итог] = SUM(H6:H[max-1])
  I[итог] = SUM(I6:I[max-1])
```

## Лист 11: Все_позиции ⭐

Все 3 385 строк из ЛСР, с автофильтром.

```
Шапка (row 5):
  A: Раздел/№
  B: № п/п
  C: № ЛСР
  D: Раздел
  E: Тип строки (Раздел / Работа / Материал / Перевозка / Итог)
  F: Подтип
  G: Тип кода (ФЕР, ФССЦ, ...)
  H: Код номер (01-01-013-04)
  I: Наименование
  J: Ед.изм.
  K: Кол-во
  L: Базис цена
  M: Индекс
  N: Цена за ед. текущая
  O: Стоимость текущая (4 кв. 2023)
  P: Стоимость на 2 кв. 2026  = O * 'Параметры_индексы'!$B$21
  Q: Группа работ (для строк Работа)  ⬅ префикс кода
  R: Коэф. рыночности (через VLOOKUP по префиксу)
     = IFERROR(VLOOKUP(LEFT(H{r},5), 'Ключевые_работы'!$B$6:$G$30, 6, FALSE), 0.85)
  S: Рыночная стоимость 2 кв. 2026 = P * R
  T: ДЕЛЬТА = P - S

Включить автофильтр:
  ws.auto_filter.ref = "A5:T{max_row}"
```

## Управление пересчётом

Все формулы пересчёта на целевую дату используют **одну центральную ячейку**:
```
'Параметры_индексы'!$B$21
```

Если пользователь хочет изменить дату — он меняет только `Параметры_индексы!B18` (количество месяцев), и пересчёт идёт по всему файлу.

## Контроль качества

После сборки **обязательно проверь сходимость**:

1. Сумма ЛСР сошлась с шапками
2. Свод_ЛСР!H[итог] = Себестоимость_итог!E18
3. Себестоимость_итог!E29 (НМЦК с НДС) ≈ обоснование НМЦК (±1%)
4. Сумма дельт работ в "Все_позиции" = "Ключевые_работы"!I[итог] (0 руб разница)
5. Себестоимость_итог!E47 = 'Ключевые_ресурсы'!G114
6. Себестоимость_итог!E48 = 'Ключевые_ресурсы'!I114
