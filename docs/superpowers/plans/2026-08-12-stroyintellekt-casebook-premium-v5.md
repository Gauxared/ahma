# План реализации премиального кейсбука V5

> **Для агентных исполнителей:** обязательно использовать `subagent-driven-development` или `executing-plans`. Каждый кейс принимается только после проверки анонимизации и доказательной границы.

**Цель:** создать 36-слайдовый форензический кейсбук, который показывает глубину метода, существующие расчётные артефакты и основания для доказательного пилота.

**Архитектура:** введение и метод доказательства создают общий стандарт, затем семь кейсов раскрываются одинаковой логикой из трёх сцен при разных композициях, после чего файл завершает синтез и проект пилота.

**Технологии:** HTML/CSS-слайды Factory, встроенные обезличенные изображения `data:`, Chrome PDF, Poppler.

## Acceptance

- Ровно 36 слайдов.
- Семь кейсов имеют по три самостоятельные сцены.
- Нет повторной идентификации объектов.
- Каждый кейс отделяет артефакт от фактического результата.
- Визуальный язык похож на экспертное расследование, а не на рекламную брошюру.
- Последние слайды приводят к доказательному пилоту на данных клиента.
