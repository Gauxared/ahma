# План реализации премиального коммерческого предложения V5

> **Для агентных исполнителей:** обязательно использовать `subagent-driven-development` или `executing-plans`. Выполнять задачи по порядку и проверять каждый диапазон слайдов до перехода к следующему.

**Цель:** создать 44-слайдовое универсальное коммерческое предложение, которое представляет «СтройИнтеллект» как крупную корпоративную систему и приводит клиента к платному следующему шагу.

**Архитектура:** один самостоятельный PowerPoint-источник с встроенными стилями и изображениями. Семь глав собираются последовательно; после каждой главы выполняются проверка содержания, повторов макетов и риска утверждений.

**Технологии:** HTML/CSS-слайды Factory 960×540 px, Montserrat, встроенные `data:`-изображения, Chrome PDF, Poppler.

## Task 1: Создать визуальную основу и каркас 44 слайдов

- [ ] **Step 1:** Создать HTML-документ без скриптов и удалённых ресурсов.
- [ ] **Step 2:** Встроить `@font-face` Montserrat как `data:` или использовать установленный Montserrat с резервным `DejaVu Sans`.
- [ ] **Step 3:** Задать `.slide` 960×540 px, печатную страницу 10×5.625 дюйма, белый фон и внутреннюю сетку.
- [ ] **Step 4:** Создать 44 пустых секции `<section class="slide" id="sN" data-source="...">`.
- [ ] **Step 5:** Проверить каркас:

```bash
python3 - <<'PY'
import re
from pathlib import Path
p = Path("tmp/stroyintellekt-commercial-premium-v5.pptx.html")
text = p.read_text(encoding="utf-8")
tags = re.findall(r'<section\b[^>]*class="[^"]*\bslide\b[^"]*"[^>]*>', text)
ids = [re.search(r'\bid="([^"]+)"', tag).group(1) for tag in tags]
assert len(tags) == 44, len(tags)
assert ids == [f"s{i}" for i in range(1, 45)], ids
assert all('data-source="' in tag for tag in tags)
print("OK: 44 slides")
PY
```

Expected: `OK: 44 slides`.
