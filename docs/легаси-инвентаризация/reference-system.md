# Инвентаризация `reference-system/` (легаси Claude Cowork, редакция v8.2)

Дата: 2026-09-08. Объём: 77 файлов, 25 МБ (из них 11,6 МБ — `ref-sys.zip`, 8,7 МБ — два PDF в `input-1/`).
Папка отслеживается git (77 файлов), исключена из Docker-образа (`.dockerignore`) и из `tsconfig` (`exclude`).

Метод сверки: md5sum для xlsx/скиллов; для промптов — построчный diff (`sort -u`) и 6-словные шинглы; для docx — извлечение текста python-docx; для xlsx — разбор XML (openpyxl в системе нет). Grep по репозиторию без `reference-system*`, `node_modules`, `.git`.

Ключевой факт, влияющий на статусы: наши `config/agents/*/source-prompt.txt` взяты **не из этой папки**, а из `reference-system-new/Выход/*_v9.6|v9.7.txt` (см. поле `sourcePrompt` в манифестах). Промпты v8.2 (docx здесь) — предшествующая редакция, переписанная авторами легаси в v9.x. Опорные базы `.xlsx` из корня манифесты читают **по месту** (`"referenceBase": "reference-system/…xlsx"`, загрузчик `platform/config/reference-base-loader.ts`), а также они целиком вошли в `config/crew/bases/СтройИнтеллект_ЕдинаяБаза_v1.0.xlsx` (листы `АРТ·`, `ДЕН·`, `НОРМ·`, `ЛЮД·`, `ВАН·`, `МАР·`, `ХАЛ·`, `ПАЛ·`, `ВИК·`, `НАС·` — те же листы, +1 строка заголовка).

## Замечания

- **Опорные базы читаются из `reference-system/`, а папка исключена из Docker-образа.** Девять манифестов указывают `"referenceBase": "reference-system/…xlsx"`; `.dockerignore` содержит `reference-system`. В контейнере все девять агентов окажутся в режиме `[БЕЗ БАЗЫ]` (загрузчик молча возвращает `undefined`). Либо копировать книги в `config/crew/bases/` (там уже лежит ЕдинаяБаза со всеми их листами) и переключить манифесты, либо монтировать папку томом — сейчас это не задокументировано как требование деплоя.
- **Дубли внутри `reference-system/` (4 копии одного скилла):** `stroiintellect-master.skill` = `skills/stroiintellect-master/…` = `_extracted_skills/master/…` = `config/skills/stroiintellect-master/`; аналогично `construction-cost-analysis.skill` = `skills/construction-cost-analysis/…`. Плюс `ref-sys.zip` (11,6 МБ) дублирует 61 файл папки. Из 25 МБ репозиторной нагрузки уникальных данных ~13 МБ.
- **Расхождение версий:** папка называется «легаси v8.2», но её отраслевые промпты (`modc/apri/unihim/uralsetstroy`) идентичны тем, что в `reference-system-new/Вход/`, а базы `.xlsx` — тем же файлам в `config/crew/bases`. То есть `reference-system/` — смесь v8.2 (9 docx, 10 баз) и материалов, вошедших без изменений в v9.x.
- **Две книги Денчика в v8.2 → одна в манифесте** (см. п.1 выше). В шапке всех v8.2 docx прямо сказано: «у Денчика два: навигатор + нормбаза».
