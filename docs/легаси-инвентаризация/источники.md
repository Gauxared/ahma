## Замечания к реализации

1. Промпты требуют тег `[ИСТОЧНИК: документ/url, дата, статус ✅/⚠]` на каждую цифру (`config/crew/core-rules.md:42,62`; `стройинтеллект-платформа/SKILL.md`) — парсеры должны возвращать дату публикации и статус (действует/отменён) вместе со значением.
2. Правило свежести «>90 дней = ⚠» (Перечень нормативки; УСС «срок годности 90 дней») — хранить дату забора.
3. `config/knowledge-sources.json` описывает только внутренние источники (reference-base, object-documents); внешних коннекторов нет — место для регистрации новых парсеров как `kind: knowledge-source` с `contour: external`.
4. В v9.x платные агрегаторы (Контур.Фокус, СПАРК) исчезли — упор на открытые госреестры; это соответствует топ-10 выше.
5. Для регионов уже есть словарь слагов Avito по 15 регионам (`config/market/поставщики.json`), его можно переиспользовать для регионального ключа ФГИС ЦС/индексов Минстроя (субъект РФ).
