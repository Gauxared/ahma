
> **Мы не конкурируем с системами управления документами и процессами.** Мы занимаем **незанятый слой** — интеллектуальный финансово-технический контроль поверх существующих систем.

### 1.2 Формула позиционирования

```
ДЛЯ:     Средних и крупных застройщиков (≥3 объектов, подрядный бюджет ≥500 млн ₽/объект)
КОТОРЫЕ:  Хотят контролировать стоимость строительства и не переплачивать подрядчикам
ПРОДУКТ:  СтройИнтеллект — цифровая служба технического заказчика
КОТОРЫЙ:  Проверяет сметы, подрядчиков и экономику объекта с помощью 9 ИИ-агентов
          и собственной расчётной модели по 250+ объектам
В ОТЛИЧИЕ ОТ: Сметных программ (считают «как положено», не «сколько стоит на самом деле»),
              СОД-систем (управляют процессами, не анализируют финансы),
              внешних аудиторов (дорого, долго, после факта)
ПОТОМУ ЧТО: Имеет собственную расчётно-аналитическую оценку стоимости,
            базу из 250+ реальных объектов и работает в контуре заказчика
```

## 2. Профиль идеального клиента (ICP) — расширенный

### 2.1 Сегменты целевого рынка

| Сегмент | Описание | Размер | Приоритет |
|---------|----------|--------|----------|
| **А. Крупные девелоперы** | ≥10 объектов, подрядный бюджет ≥2 млрд ₽/год | ~50–100 компаний | 🔴 Первичный |
| **Б. Средние девелоперы** | 3–10 объектов, бюджет 500 млн–2 млрд ₽/год | ~200–300 компаний | 🟡 Вторичный |
| **В. Корпоративные заказчики** | Промышленное строительство, капстроительство | ~100–200 компаний | 🟡 Вторичный |
| **Г. Генподрядчики** | Крупные генподрядные организации | ~50–100 компаний | 🟢 Перспективный |

### 2.2 Scoring-модель квалификации лида

| Критерий | 0 баллов | 1 балл | 2 балла | 3 балла |
|----------|---------|--------|---------|---------|
| **Одновременных объектов** | 1 | 2–3 | 4–10 | >10 |
| **Подрядный бюджет / объект** | <200 млн | 200–500 млн | 500 млн–2 млрд | >2 млрд |
| **Служба техзаказчика** | Нет | Частичная | Есть | Собственная с ≥5 чел. |
| **История закрытых объектов** | Нет | 1–2 | 3–5 | >5 |
| **ИТ-зрелость** | Excel только | 1С базовый | 1С + СОД | Полный ИТ-контур |
| **Готовность к пилоту** | Нет | Теоретический интерес | Готов обсуждать | Готов дать данные |
| **Бюджет на ИТ / цифровизацию** | Нет | <10 млн | 10–30 млн | >30 млн |

**Порог квалификации:** ≥ 12 баллов = квалифицированный лид

### 2.3 Карта участников покупки (Buying Committee)

| Роль | Кто | Что его волнует | Наше сообщение |
|------|-----|-----------------|----------------|
| **Экономический покупатель** | Генеральный директор, собственник | ROI, стоимость ошибок, контроль | «Окупается на первом объекте» |
| **Технический покупатель** | Технический заказчик, директор по строительству | Точность, скорость, удобство | «Усиливает команду, не заменяет» |
| **Пользователь** | Сметчик, ПТО, снабженец | Простота, результат, доверие к числам | «Каждое число с источником» |
| **Привратник** | ИТ-директор, служба ИБ | Безопасность, интеграции, поддержка | «On-premise, локальные модели» |
| **Влиятель** | Финансовый директор | Финмодель, маржа, кассовые разрывы | «3 сценария маржи, прогноз БДДС» |

## 3. Go-to-Market стратегия

### 3.1 Воронка продаж

```
                    ОСВЕДОМЛЁННОСТЬ
                    ┌──────────────┐
                    │ Отраслевые   │ ← Конференции, публикации,
                    │ мероприятия  │   нетворкинг, рекомендации
                    └──────┬───────┘
                           │
                    ИНТЕРЕС
                    ┌──────┴───────┐
                    │ Первый       │ ← Презентация + демо
                    │ контакт      │   «А покажите на примере»
                    └──────┬───────┘
                           │
                    ОЦЕНКА
                    ┌──────┴───────┐
                    │ Предпродажный│ ← Расчёт на 1–2 закрытых
                    │ расчёт       │   объектах клиента
                    └──────┬───────┘
                           │
                    РЕШЕНИЕ
                    ┌──────┴───────┐
                    │ КП + ROI     │ ← Индивидуальный расчёт
                    │ обоснование  │   эффекта и бизнес-кейс
                    └──────┬───────┘
                           │
                    СДЕЛКА
                    ┌──────┴───────┐
                    │ Контракт +   │ ← Договор, оплата,
                    │ внедрение    │   старт работ
                    └──────────────┘
```

### 3.2 Каналы привлечения (приоритизированные)

| # | Канал | Действие | Ожидаемый результат | Приоритет |
|---|-------|---------|--------------------|----|
| 1 | **Прямые продажи (outbound)** | Точечные встречи с ЛПР из списка ICP | 3–5 квалифицированных встреч / месяц | 🔴 |
| 2 | **Конференции и форумы** | Выступления на строительных мероприятиях (Сочи, НК, ЕРЗ) | Охват + 5–10 лидов / мероприятие | 🔴 |
| 3 | **Рекомендации (АПРИ)** | Запросить рекомендации у АПРИ после успешного внедрения | 2–3 тёплых контакта | 🟡 |
| 4 | **Публикации и кейсы** | Статьи в «Строительном эксперте», CRE, ЕРЗ | Экспертное позиционирование | 🟡 |
| 5 | **Партнёрства** | Совместные предложения с интеграторами 1С, СОД | Расширение воронки | 🟢 |

### 3.3 Ценовая стратегия

| Стратегия | Описание | Когда применять |
|-----------|---------|----------------|
| **Стратегическое внедрение** (22,5–25 млн) | Сниженная цена для референсного кейса | Клиент = публичный пример, готов на PR |
| **Целевая продажа** (29,9–32,9 млн) | Стандартная коммерческая сделка | Квалифицированный ICP, стандартный объём |
| **Premium** (34,9+ млн) | Расширенный функционал, множество интеграций | Крупный холдинг, сложный контур |
| **Предпродажный расчёт** (бесплатно) | Расчёт на 1–2 закрытых объектах | Всегда, это инструмент продажи |

> **Важно:** Цена 22,5 млн ₽ (АПРИ) — это цена **первого промышленного внедрения**. Она НЕ должна стать стандартной ценой для рынка. Для следующего клиента — **стартовая 34,9 млн ₽, целевая 29,9–32,9 млн ₽**.

## 8. Риски коммерциализации и как их снижать

| # | Риск | Вероятность | Влияние | Митигация |
|---|------|-------------|---------|----------|
| 1 | **Длинный цикл сделки** (6+ мес.) | Высокая | Высокое | Предпродажный расчёт сокращает цикл. Работать с экономическим покупателем. |

| 4 | **Юридическое смешение** с функцией техзаказчика | Средняя | Высокое | Во всех материалах: «цифровой инструмент службы, не юридический технический заказчик». |
| 5 | **Конкурент скопирует подход** | Средняя | Среднее | Конкурентный барьер = база 250+ объектов + опыт калибровки. Трудно воспроизвести. |
| 6 | **Проблема «чёрного ящика»** | Средняя | Среднее | Каждое число — с источником, годом, статусом. Расчётный модуль — детерминированный. |

Система выдаёт обоснованную рекомендацию с вариантами; принятие управленческих решений остаётся за ответственным лицом заказчика.»

**Формулировка по ценности:**

> Показатель «2–5% экономии» является **иллюстративной оценкой** на основе анализа закрытых объектов. Фактический экономический эффект определяется по результатам расчёта на конкретных данных заказчика и подтверждается протоколом.
