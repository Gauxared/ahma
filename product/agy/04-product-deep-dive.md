### 4.1 Девелопмент (текущий фокус)

- **Целевой клиент:** Застройщик, девелопер
- **Ключевой сценарий:** Проверка стоимости и экономики объекта
- **Полный набор:** 9 агентов + расчётный модуль + финмодель
- **Подтверждённый клиент:** АПРИ

### 4.2 Генподряд (следующий горизонт)

- **Целевой клиент:** Генподрядная организация
- **Ключевой сценарий:** Контроль субподрядчиков, проверка выполнения
- **Готовность:** Промт v1.0 уже существует (reference-system)
- **Адаптация:** Модификация линз ГИП, Сметчик, Подряд под контекст ГП

### 4.3 Light (инженерные компании)

- **Целевой клиент:** Инженерная компания (ВКХ, монтаж, сети)
- **Ключевой сценарий:** Проверка смет по инженерному разделу
- **Готовность:** Промты v1.0–v1.1 существуют (Родионыч, Игнатыч, Захарыч)
- **Особенность:** Сокращённый набор агентов, меньше требований к инфраструктуре

### 5. Пользовательские сценарии (User Stories)

#### 5.1 Главный сценарий: «Проверка нового объекта»

```
ДЕЙСТВУЮЩЕЕ ЛИЦО: Руководитель техзаказчика

ПРЕДУСЛОВИЕ: Получены документы по новому объекту

СЦЕНАРИЙ:
1. Загружает смету (Excel/XML) и ведомость объёмов
2. Указывает тип продукта и площадь
3. Выбирает режим анализа (экспресс / стандарт / эксперт)
4. Система запускает 9 агентов параллельно
5. Видит прогресс по каждому агенту (живая лента)
6. Получает сводный результат:
   - Реестр отклонений (с суммами)
   - Себестоимость ₽/м²
   - Финансовая модель (3 сценария)
   - Рекомендации по каждой функциональной зоне
7. Скачивает Excel с формулами и Word-записку
8. Передаёт результат команде для принятия решений

РЕЗУЛЬТАТ: Объект проверен за 15 мин – 5 часов
вместо 1–2 недель ручной работы
```

#### 5.2 Сценарий: «Сравнение подрядчиков»

```
ДЕЙСТВУЮЩЕЕ ЛИЦО: Снабженец / Руководитель тендера

ПРЕДУСЛОВИЕ: Получены 3+ КП от подрядчиков

СЦЕНАРИЙ:
1. Загружает коммерческие предложения
2. Система приводит позиции к сопоставимому виду
3. Показывает разброс цен по каждой позиции
4. Выявляет аномалии (аномально дешёвые / дорогие)
5. Формирует собственную расчётную оценку стоимости
6. Показывает рекомендованный диапазон цен

РЕЗУЛЬТАТ: Обоснованная позиция для переговоров
с подрядчиком, подкреплённая данными по 250+ объектам
```

#### 5.3 Сценарий: «Проверка КС-2/КС-3»

```
ДЕЙСТВУЮЩЕЕ ЛИЦО: Инженер ПТО

ПРЕДУСЛОВИЕ: Подрядчик предоставил формы КС-2 и КС-3

СЦЕНАРИЙ:
1. Загружает формы КС-2 и КС-3
2. Агент ПТО оценивает расхождения
3. Агент Экономист оценивает финансовое влияние на бюджет и маржу
4. Система формирует сводку расхождений с суммами

РЕЗУЛЬТАТ: Понимание финансового влияния расхождений
до подписания актов
```

#### 5.4 Сценарий: «Проверка договора подряда»

```
ДЕЙСТВУЮЩЕЕ ЛИЦО: Юрист / Руководитель проекта

СЦЕНАРИЙ:
1. Загружает проект договора подряда
2. Агент Юрист анализирует: аванс, удержания, цену,
   штрафы, приёмку, гарантии
3. Формирует перечень существенных рисков
4. Даёт рекомендации по урегулированию

РЕЗУЛЬТАТ: Перечень рисков и предложения по формулировкам
до подписания договора
```

### 6. Метрики продукта (Product Metrics)

#### 6.1 North Star Metric

> **Суммарный объём предотвращённых переплат клиентами** (₽)

Это единственная метрика, которая отражает реальную ценность продукта. Все остальные метрики — ведущие индикаторы к ней.

#### 6.2 Ведущие индикаторы

| Категория | Метрика | Цель (первый год) |
|-----------|---------|-------------------|
| **Точность** | % позиций, корректно извлечённых из документов | ≥ 95% |
| **Полнота** | % нарушений, покрытых системой (vs ручная проверка) | ≥ 70% |
| **Скорость** | Время экспресс-анализа | ≤ 15 мин |
| **Качество** | % пунктов чек-листа по каждому агенту | ≥ 80% |
| **Использование** | Среднее число анализов / месяц / клиент | ≥ 10 |
| **Удержание** | % клиентов, продливших поддержку после 12 мес. | ≥ 80% |
| **Экономика** | Подтверждённый эффект / стоимость внедрения | ≥ 2x |
