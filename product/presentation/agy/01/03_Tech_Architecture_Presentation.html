Базовые принципы архитектуры

Платформа СтройИнтеллект изначально проектировалась для Enterprise-сегмента, где безопасность коммерческой тайны и масштабируемость ставятся во главу угла.

Архитектура построена по принципу микросервисов, разделяющих тяжёлые задачи (парсинг 500-страничных PDF, вызов LLM) и детерминированную математику (расчёт БДДС и себестоимости).

Основа системы — высокопроизводительный FastAPI Gateway, управляющий очередями через брокеры сообщений (RabbitMQ / Redis).

Информационная безопасность: Система двух контуров

Внутренний контур (Закрытый)

Здесь обрабатывается коммерческая тайна Заказчика: сметы, финмодели, договоры и историческая база данных.

Работает исключительно на моделях с открытыми весами (например, Llama 3 / Qwen), развёрнутых на серверах внутри вашей инфраструктуры. Выход в интернет физически закрыт.

Внешний контур (Анонимный)

Применяется для задач, требующих парсинга рыночных цен или работы с внешними API.

Передача данных во внешний контур выполняется только по согласованному регламенту с обязательным маскированием и анонимизацией всех атрибутов компании.

Проблема галлюцинаций решена на уровне архитектуры

1. Роль нейросетей

Большие языковые модели (LLM) используются исключительно для семантического анализа.

Они читают PDF/XML, находят нужные сущности, классифицируют риски в договорах, но никогда не складывают числа.

2. Формализация (JSON)

Нейросеть извлекает данные и строго формализует их в структурированный JSON-формат, который валидируется по схеме (Pydantic).

3. Расчётный модуль

Финансовую модель, себестоимость и итоговые суммы считает детерминированный движок на базе Decimal.

Нулевой риск арифметических "галлюцинаций" и идеальная точность.

Интеграция с существующим ИТ-ландшафтом

Входные данные (Input)

Система не требует ручного вбивания данных. Она поддерживает парсинг:

  • Гранд-Смета (XML) и Главгосэкспертиза.
  • Неструктурированные сметы в Excel (любой формат).
  • Сканы PDF (через встроенный модуль OCR).

API позволяет автоматически забирать документы прямо из вашего 1С:ДО, ERP или СОД (Pilot-BICE).

Выходные данные (Output)

Результат работы — это не просто красивый дашборд. Система отдаёт:

  • Размеченный реестр отклонений (XLSX).
  • Готовую финансовую модель.

Через REST/SSE API можно вернуть результаты проверки обратно в ERP для блокировки платежей или запуска процессов согласования.
