# Кейс-база СтройИнтеллект v8.1 + Форматы Штаба

## КЕЙС 1: Каранайаул, Дагестан
**Тип:** Капремонт дороги, 10 км, B2G  
**НМЦК:** 413 млн руб., 2026  
**Климатический дедлайн:** 31 октября (горный Дагестан)

### Уроки (вшиты в стандарты команды)

**К-1: Битум — системный риск**
Цена в ЛСР: ~40 000 руб./т (сметная, 2023). Рынок: ~105 000 руб./т (2026, СКФО).
Коэффициент: 2,6×. При объёме X тонн = убыток Y млн. Не исключение — закономерность.
→ Марина: битум + асфальтобетон проверяются ПЕРВЫМИ в лид-тайм карте.
→ Ваныч: строка «коррекция битума» в каждом сметном проекте СКФО.

**К-2: ЛСР 08-01 выпала из свода**
3,5 млн рублей потеряно. Причина: механическая ошибка при сводке.
→ Людмила: явная сверка суммы ЛСР vs свод. Обязательная строка: «Разница: [X]. Если >0 — найти».

**К-3: Финмодель «в работе» 3 недели**
«В работе» = нет финмодели. Нет финмодели = нет условий субподряда.
→ Артемий: «в работе» без даты = блокер. Ваныч должен дать первичную финмодель в конце Такта 2.

**К-4: «Запросить» без плана = ноль**
Задание «запросить КП» без конкретики → через неделю одно КП из Грозного в рублях без доставки.
→ Марина: «Запросить 3 КП по [позиция], по [объём], с доставкой в [место], к [дата]» — единственный формат.

**К-5: ИД до первой лопаты**
Работы начались без оформленной ИД. Предписание ГСН.
→ Палыч: чеклист старта = Такт 1. Без заполненного чеклиста Такт 4 не открывается.

**Продуктовый инсайт Каранайаула:**
«Агенты без документной цепочки = сироты: знают своё, не видят соседнее.
 Система должна не давать агенту отвечать «в работе» без конкретной даты — это блокер интерфейса.»

## КЕЙС 2: Школа №19, Москва
**Тип:** ДОО + СОШ, строительство, B2G  
**Заказчик:** ГКУ ДИОМ, Москва  
**НМЦК:** 2,02 млрд руб., 2026  
**Стадия при входе:** команда зашла в активно строящийся объект

### Уроки

**Ш-1: 3 работы шли БЕЗ ИД (март–май)**
Работы: [виды работ без АОСР]. Нарушение: Приказ Минстроя № 344/пр.
Следствие: предписание ГСН + риск не подписания КС-2 на эти объёмы.
→ Палыч v8: статус ИД = первый пункт любого отчёта. Светофор ежедневно.

**Ш-2: ГУ 5% = 101 млн вне оборота**
Обеспечение исполнения контракта: ГУ 5% × 2,02 млрд = 101 млн.
На счёте заморожены 5 лет. Стоимость капитала 10–15%: потери 30–50 млн.
Альтернатива: БГ = 1,5%/год × 101 млн × 1,5 лет = ~2,3 млн.
Экономия при замене: 30–50 млн – 2,3 млн ≈ 28–48 млн.
→ Виктор v8: инициировать замену ГУ → БГ в Такт 1. Письмо Заказчику.
→ Ваныч v8: строка «ГУ vs БГ» обязательна в каждой B2G финмодели.

**Ш-3: «1 компл.» без расшифровки = 237 млн**
«Технологические решения: 1 компл. = 237 млн» (11,8% НМЦК).
Невозможно включить в ВОР, невозможно контролировать.
→ Людмила: «1 компл.» ≥ 5% НМЦК = блокер немедленно.
→ Виктор: официальный запрос расшифровки к Заказчику.

**Ш-4: Кассовый разрыв июнь 2027**
Найден за 13 месяцев от даты входа команды.
Источник: авансовая схема + задержка КС-2 + высокий расход на субподряд в Q1 2027.
→ Ваныч v8: кассовый разрыв ищется на ВХОДЕ, всегда, без запроса — золотой стандарт.

**Ш-5: Витражи 250 млн, лид-тайм 12–16 недель**
Заказ не сделан. Монтаж по КСГ через 35 дней.
При лид-тайме 16 недель: заказ должен был быть 5 месяцев назад.
→ Марина v8: лид-тайм карта ТОП-5 за первые 4 часа работы на объекте.
→ Артемий: любая позиция > 8 недель лид-тайма = приоритет №1 в Такт 3.

**Продуктовый инсайт Школы №19:**
«ГУ 5% = 101 млн вне оборота — продукт должен считать это автоматически.
 Кассовый разрыв за 13 месяцев — это не случайность, это методология.
 Продукт должен делать это по умолчанию, не по запросу.»

## КЕЙС 3: ЧТЗ-Уралтрак, Моторный корпус
**Тип:** Промышленный, модернизация теплоснабжения, первый кейс ГИПа  
**Объём:** 22 МВт, 110 вентиляторных конвекторов Volcano, ~10,5 км труб  
**Стоимость:** ~200 млн «под ключ»  
**Дата:** 30.05.2026

### Уроки (уроки Денчика Д-1 — Д-6)

**Д-1: Геометрия первична**
84 оси × 12 м = 996 м → длины Ø76 и Ø57 выведены от осей. Δ с калькуляцией = 0,3%.
→ Денчик: любая длина трубопровода/кабеля/трассы — сначала из осей, потом сверка.

**Д-2: Двойная сверка по v И R**
Ø219 для 4 МВт: v = 1,46 м/с (🟡 допустимо), R = 150 Па/м (🟡 для короткой обвязки).
Ø57 на 1 Volcano: v = 0,25 (избыточна), R = 18 → Ø40 хватило бы.
→ Денчик: два критерия обязательны: скорость И удельные потери.

**Д-3: Состав, а не только цифры**
На плане 5 ИТП. В ТЗ: 7 зданий → ожидается 7 ИТП. «5 ≠ 7» → флаг.
→ Денчик: сверять количество объектов, систем, точек. Состав, а не только числа.

**Д-4: Ø219 выпала из спецификации**
~160 м Ø219 = ~10–12 млн. Трубы не было в спецификации.
→ Денчик: после гидравлики — проверить, все ли диаметры в спецификации. Отсутствие ≠ «не нужно».

**Д-5: Нормы с номером пункта**
«По СП 124» — не ссылка. «СП 124.13330.2012 п.6.40» — ссылка.
→ Денчик (и все агенты): каждое нормативное требование = документ + пункт.

**Д-6: Статус норматива — СНАЧАЛА** ← самый важный
С 01.09.2024: ПП РФ № 815 (обязательный перечень) — ОТМЕНЁН.
РД-11-02-2006, РД-11-05-2007 — ОТМЕНЕНЫ. Действуют: Приказы № 344/пр и № 1026/пр.
→ Все агенты: норматив без подтверждённого статуса «действует» = допущение.
→ Строки ❌ в нормбазе Денчика: стоп, не применять в РД.

**Продуктовый инсайт ЧТЗ:**
«Инженерная истина ДО ВОР закрывает корневую ошибку Каранайаула и Школы №19 —
 считать на необоснованных объёмах. Денчик — первый, потому что без физики деньги бессмысленны.»

## ФОРМАТЫ ШТАБА

### /браинсторм [тема]
5–7 идей от разных специализаций. Без цензуры. Формат:
```
АРТЕМИЙ: [идея через линзу РП]
ДЕНЧИК:  [идея через линзу ГИПа]
ВАНЫЧ:   [идея через линзу денег]
ЛЮДМИЛА: [идея через линзу сметы]
...
СИНТЕЗ: [если есть пересечение] или «Синтеза нет — выбор за Артемием»
ИНСАЙТ: [одна фраза]
ДЕЙСТВИЕ: [кому, что, когда]
```

### /ретро [этап/объект]
```
ЧТО РАБОТАЛО:   [конкретно, что дало результат]
ЧТО НЕ РАБОТАЛО: [конкретно, с причиной]
ЧТО ИЗМЕНИТЬ:   [конкретное действие для следующей версии]
КТО ОТВЕЧАЕТ:   [конкретный агент или Артемий]
ИНСАЙТ СЕССИИ: [одна фраза — главное]
```

### /позиции [вопрос]
Каждый агент: 1–2 предложения от своей специализации. Без длинных обоснований.

### /примортем [объект/решение]
```
«Представь: [дата через 6 мес.]. Объект [провалился/задержан/убыточен].
7 причин, почему это произошло:
1. [причина] → Проверь прямо сейчас: [что, у кого]
2. ...
Самый вероятный сценарий провала: [X].
Минимальное, что нужно проверить СЕГОДНЯ: [Y].»
```

### /критика [идея]
```
ЧТО ХОРОШО: [конкретные сильные стороны]
РИСКИ:      [конкретные, с оценкой вероятности и суммой]
СЛАБОЕ МЕСТО: [самое уязвимое]
ВОПРОС, КОТОРЫЙ НИКТО НЕ ЗАДАЛ: [трудный вопрос]
РЕКОМЕНДАЦИЯ: [принять / доработать / отклонить]
```

### Завершение любого обсуждения в Штабе
```
═══════════════════════════
ИНСАЙТ СЕССИИ: [одна фраза — главное, что поняли]
ДЕЙСТВИЕ: [конкретный следующий шаг]
КОМУ: [Артемию (операционное) / конкретному агенту / на следующую сессию Штаба]
═══════════════════════════
```

## Применение уроков как автоматических проверок

| Ситуация | Урок | Автоматическая реакция |
|---|---|---|
| Любой B2G объект | Ш-2 | Виктор: письмо о замене ГУ → БГ в Такт 1 |
| Позиция «1 компл.» в ЛСР | Ш-3 | Людмила: блокер + запрос расшифровки |
| Финмодель впервые | Ш-4 | Ваныч: кассовый разрыв ищется на входе |
| Наличие витражей/оборудования > 5 млн | Ш-5 | Марина: лид-тайм первым |
| Объект в СКФО с битумом | К-1 | Марина: цена битума от рынка, не сметы |
| Свод ЛСР составлен | К-2 | Людмила: сверка суммы обязательна |
| Норматив в ТЗ/РД | Д-6 | Денчик: проверка статуса ДО использования |
| Длины в калькуляции | Д-1 | Денчик: пересчёт от осей, потом сверка |
| Инженерный расчёт | Д-4 | Денчик: полнота спецификации после расчёта |
