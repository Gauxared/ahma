# Нормативная база СтройИнтеллект v8.1

## Правило статуса источника (Урок Д-6 + тег [ИСТОЧНИК] Людмилы)

**Единое правило для всех 9 агентов:**
> Любая цифра, норма или ссылка без источника, даты и подтверждённого статуса «действует» = ДОПУЩЕНИЕ, а не данные.
> Ссылка на отменённый документ без оговорки = профессиональная ошибка.

**Тег [ИСТОЧНИК] — формат:**
- Инженерный: «[ИСТОЧНИК: СП 124.13330.2012 п.6.40 — удельные потери ≤ 100 Па/м, статус: ✅ действует]»
- Сметный: «[ИСТОЧНИК: ФЕР-27-04-001, 4кв2000, индекс 11.56, регион 05, дата: апрель 2026]»
- Рыночный: «[ИСТОЧНИК: прайс ООО «Гамма-Бетон» г.Махачкала, апрель 2026]»
- Нормативный: «[ИСТОЧНИК: Приказ Минстроя № 344/пр от 02.04.2020, статус: ✅ действует]»

## Руководящая база СтройИнтеллект (общая)

**Файл:** Руководящая_база_СтройИнтеллект_общая_v1.0.xlsx  
**Листы:** 12 листов по неинженерным фронтам  
**Охват:** Сметы, госзаказ, договоры, закупки, ИД, охрана труда, финансы

Инженерный слой хранится отдельно в нормбазе Денчика (183 документа, 16 листов).  
Лист J общего документа ссылается на нормбазу Денчика как указатель.

**Принцип использования:**
- При любой ссылке на норматив → сначала проверить по руководящей базе
- При обнаружении расхождения с проектной документацией → флаг + ссылка на актуальный документ
- При работе с госконтрактом → 44-ФЗ/223-ФЗ раздел обязателен

## Быстрый чеклист проверки нормативной ссылки

Перед любым использованием нормативного документа в расчёте или ответе:

```
□ Документ входит в Стоп-лист? → СТОП, найти замену
□ Год редакции актуальный? (СП 45 → 2017, не 2012; СП 24 → 2021, не 2011)
□ Номер пункта указан? («п.6.40» обязателен)
□ Строка 🔎 или 📋 в нормбазе? (📋 = проверить перед РД)
□ Источник добавлен в ответ тегом [ИСТОЧНИК: ...]?
```

Если хоть один пункт не выполнен → допущение со звёздочкой (*), явно указать пользователю.
