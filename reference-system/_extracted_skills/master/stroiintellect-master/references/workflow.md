# Рабочий процесс СтройИнтеллект: Такты, Документный поток, КСГ

## ТАКТЫ 0–4 — Детальный протокол

### ТАКТ 0 (≤ 2 часов от получения задания)
**Исполнитель:** Настенька
**Продукты:**
1. Паспорт объекта (шаблон):
   ```
   ОБЪЕКТ: [название, адрес]
   ЗАКАЗЧИК: [наименование, контакт, договор №]
   НМЦК / Цена договора: [сумма, НДС]
   СРОКИ: начало [дата] → сдача [дата] → климатический дедлайн [дата]
   КОМАНДА: РП — Артемий | ГИП — Денчик | [остальные]
   ИНЖЕНЕРНЫЙ ПРОФИЛЬ (Денчик): [ждём — ТАКТ 1]
   СТАТУС ИД: ждём Палыча — ТАКТ 1
   ТОП-5 РИСКОВ: [заполняет Артемий после ТАКТ 4]
   ```
2. Реестр поручений (шаблон):
   ```
   № | Агент | Задание | Дедлайн | Статус | Результат
   1 | Денчик | Инж. заключение | День 1 | 🔴 | —
   2 | Людмила | ВОР + конъюнктура | День 1 | 🔴 | —
   ...
   ```

---

### ТАКТ 1 (День 1, параллельно)

**ДЕНЧИК (инженерный вход):**
- Читает ТЗ, РД или описание объекта
- Составляет нормативный профиль (какие СП/ГОСТ применяются, статус)
- Делает инженерное заключение по 5-блочному стандарту
- Выдаёт ВОР с геометрическим обоснованием (Блок 2)
- Ставит флаги: «5 ИТП ≠ 7 зданий», «Ø219 нет в спеке», «ПП 815 отменён»
- → Передаёт ВОР Людмиле, нагрузки Ваньчу, спецификацию Марине, ТТ Халилю

**ЛЮДМИЛА (сметный вход):**
- Принимает ВОР от Денчика (с геом. обоснованием)
- Делает маппинг ЛСР (сводная таблица ЛСР + проверка суммы vs свод)
- Конъюнктурный анализ ТОП-5 ресурсов в рублях
- Ставит флаги: «1 компл.» ≥ 5%, выпавшие ЛСР
- Формат ВОР: № | Вид | Ед. | Кол-во | Цена | Сумма | Доля | Старт КСГ | Статус

**ПАЛЫЧ (чеклист старта):**
```
□ Приказ о начале производства работ подписан?
□ Общий журнал производства работ оформлен?
□ Лаборатория найдена? Аккредитация проверена (по виду работ)?
□ ПОС утверждён?
□ Список АОСР составлен и передан прорабу?
□ Ответственный за ИД назначен?
□ Журналы специальных работ (сварка, бетон, изоляция) готовы?
```

**ВИКТОР (аудит договора):**
```
Обязательные пункты проверки:
1. ГУ 5% vs БГ → при B2G: письмо Заказчику сразу (считает Ваныч)
2. Цена твёрдая или открытая? (ст. 710 актуальна при твёрдой)
3. Порядок подписания КС-2: срок, условия, штрафы
4. «1 компл.» ≥ 5% НМЦК без расшифровки → запрос
5. Аванс, порядок оплаты, условие back-to-back с субподрядом
6. Дата КС: 35+ дней от начала монтажа витражей/оборудования → флаг
```

---

### ТАКТ 2 (День 2, ТОЛЬКО после ВОР от Людмилы и физики от Денчика)

**ВАНЫЧ (финансовая модель):**

Входные данные (ОБЯЗАТЕЛЬНЫ):
- ВОР с суммами от Людмилы
- Нагрузки/объёмы от Денчика
- Аванс, порядок оплаты из договора (Виктор)

Структура финмодели:
```
1. БДР по месяцам: выручка (КС-2 подписана) vs расходы
2. БДДС по месяцам: cash in vs cash out
3. Разрыв БДР/БДДС = кассовый разрыв → если есть → 3 варианта закрытия
4. ТРИ СЦЕНАРИЯ: Базовый / Реалистичный (-15% выручка +10% расходы) / Стресс
5. B2G строка: «ГУ 5% = [X млн] vs БГ [1,5%/год × X × срок] = экономия [Y млн]»
6. ПОТОЛКИ → таблица: Пакет | Потолок | Бюджет | Дедлайн → к Халилю и Марине
```

---

### ТАКТ 3 (Дни 2–3, после потолков от Ваныча)

**МАРИНА (лид-тайм карта):**
```
ТОП-5 позиций по сумме:
Позиция | Объём | Поставщик 1 | Цена | Лид-тайм | Поставщик 2 | ...
Флаги: всё, что > 8 недель → немедленно Артемию
Для каждой позиции: 3 КП с контактами и условиями оплаты
```

**ХАЛИЛЬ (скоринг субподрядчиков):**
```
Ведомость распределения работ:
Пакет | Объём | Сложность | Требования (НАКС?) | Потолок (от Ваныча)

Скоринг кандидатов (по каждому):
Финотчётность 3 года → оборот, прибыль, долги
НАКС / СРО → по виду работ
Опыт аналогичных объектов (кол-во, сумма, рекомендации)
Оборудование и ресурсы
Итог: балл + рекомендация + условия предложения
```

---

### ТАКТ 4 (Дни 5–7)

**АРТЕМИЙ (синтез → вердикт):**

Собирает все результаты тактов 1–3. Даёт вердикт по трём цветам:

```
🟢 Старт разрешён — все CRITICAL закрыты, финмодель ≥ плановой маржи, ИД готова
🟡 Условный старт — [список условий]. Старт возможен при закрытии: [что, кто, когда]
🔴 Стоп — [критическая причина]. Без [X] начинать нельзя.
```

Обязательный примортем перед вердиктом:
«7 причин, по которым этот объект может завершиться с задержкой и маржой 2%:
1. [причина + как проверить прямо сейчас]
...»

## ДОКУМЕНТНЫЙ ПОТОК — Граф «кто что создаёт и кому передаёт»

```
ТЗ/РД/Договор
    ↓
ДЕНЧИК: Инж. заключение + ВОР (геом.) + нагрузки + спецификация + ТТ субподряду
    ├─→ ЛЮДМИЛА: ВОР → ЛСР-маппинг → конъюнктура → [ИСТОЧНИК]-цифры
    │       ↓
    │   ВАНЫЧ: финмодель + 3 сценария + потолки
    │       ├─→ МАРИНА: лид-тайм карта + 3 КП ТОП-5
    │       └─→ ХАЛИЛЬ: ведомость распределения + скоринг + условия
    ├─→ ВИКТОР: аудит договора + флаги рисков + инициатива БГ
    ├─→ ПАЛЫЧ: чеклист старта + реестр АОСР
    └─→ НАСТЕНЬКА: паспорт + реестр поручений + КСГ
                        ↓
              АРТЕМИЙ: синтез → вердикт → решение
```

## КСГ — Правила построения

1. **От дедлайна назад.** Клиент называет дату сдачи → все даты от неё.
2. **Климатический буфер.** Для РФ: ноябрь–апрель = зима. Буфер ≥ 12 дней на климатические риски.
3. **Критический путь.** Позиции с лид-таймом > 8 недель → встают ПЕРВЫМИ. Заказ материала с лид-таймом 16 недель = неделя 1.
4. **Без «Такт 2 до ВОР».** КСГ не финализируется без ВОР от Людмилы.
5. **Формат строки КСГ:**
   ```
   № | Вид работы | Объём (ВОР) | Исполнитель | Начало | Конец | Статус ИД | Предшественник
   ```

---

## Управление сценариями

**Базовый сценарий** — «как продано». Создаётся при подписании договора. Заморожен. Точка отсчёта план/факт.

**Рабочий сценарий** — «как делаем». Живой план. Обновляется при каждом изменении.

**Правило:** Кнопка «Утверждение Рабочего сценария» — только Артемий. До утверждения — гипотеза. Такт 2 не начинается без утверждённого Рабочего сценария.

## Критические правила протокола (нарушение = системная ошибка)

| Правило | Последствие нарушения |
|---|---|
| Ваныч без ВОР от Людмилы | Финмодель на «воздухе» → убыток как в Каранайауле |
| Людмила без ВОР от Денчика | Смета на необоснованных объёмах → ошибка 30–40% |
| Марина без потолков от Ваныча | Закупка выше бюджета → кассовый разрыв |
| Такт 4 без закрытых CRITICAL | Вердикт без оснований → риск на старте |
| ИД без Палыча с первого дня | Предписание ГСН → штраф + останов работ |
| Договор без Виктора | Пропущенный риск ГУ/БГ → 30–50 млн потерь |
