## Лист 3: Параметры_индексы (управляющий)

**Это самый важный лист с точки зрения логики**. Изменение одной ячейки (`B18`) должно пересчитывать весь файл.

```
B5: Дата обоснования НМЦК
B6: Базовый прогнозный индекс на дату обоснования
B7: Ежемесячный прогнозный индекс

B17: Целевой квартал расчёта (текст)
B18: Кол-во месяцев до целевой даты ← УПРАВЛЯЮЩАЯ
B19: Индекс перевода (4кв.2000 → 4кв.2023)

B21: =B6*POW(B7,B18) ← СОВОКУПНЫЙ ИНДЕКС
     На него ссылаются все формулы пересчёта
```

## Лист 9: Ключевые_ресурсы (материалы)

Все ключевые материалы агрегируются и группируются:

| Колонка | Содержимое |
|---|---|
| A | № позиции |
| B | Наименование материала |
| C | Единица измерения |
| D | Кол-во (суммарно из всех ЛСР) |
| E | Цена в текущих ценах 4 кв. 2023, руб/ед |
| F | =E×B21 (сметная цена на 2 кв. 2026) |
| G | =F×D (сметная стоимость) |
| **H** | 🟢 **Рыночная цена 2 кв. 2026, руб/ед** ← РЕДАКТИРУЕТСЯ |
| I | =H×D (рыночная стоимость) |
| J | =G-I (дельта) |
| K | =J/I (% дельты) |
| L | Источник рыночной цены |
| M | =H/F (коэф. рынок/смета — для построчного расчёта) |

Группировка материалов по категориям:
- Асфальтобетон и битумы
- Минеральные материалы (ПГС, песок)
- Щебень
- Бетоны и растворы
- Сборные ж/б изделия
- Металлы и арматура
- Обустройство дороги
- Гидроизоляция и герметизация
- Буровзрывные материалы
- Транспортные расходы
- Прочие

Внизу — итог:
```
G114 = SUMIFS(G6:G113, A6:A113, ">0")  // сметная (где есть рынок)
I114 = SUMIFS(I6:I113, A6:A113, ">0", H6:H113, ">0")  // рыночная
J114 = SUMIFS(J6:J113, A6:A113, ">0", H6:H113, ">0")  // дельта
G115 = SUMIFS(G6:G113, A6:A113, ">0")  // справочно: ВСЕ материалы
```

## Лист 11: Все_позиции (детали)

Все 3 385 позиций из всех ЛСР, с автофильтром.

| Колонка | Содержимое |
|---|---|
| A | Раздел / № |
| B | № п/п в ЛСР |
| C | № ЛСР |
| D | Раздел внутри ЛСР |
| E | Тип строки (Раздел / Работа / Материал / Перевозка / Итог) |
| F | Подтип |
| G | Код тип (ФЕР/ФССЦ/...) |
| H | Код номер |
| I | Наименование |
| J | Ед. изм. |
| K | Кол-во |
| L | Базисная цена за ед. |
| M | Индекс |
| N | Цена за ед. (текущая) |
| O | Стоимость текущая (4 кв. 2023) |
| P | =O×B21 (стоимость на 2 кв. 2026) |
| Q | **Группа работ** (для строк типа Работа) |
| R | **Коэф. рыночности** (через VLOOKUP из Ключевые_работы) |
| S | **Рыночная стоимость 2 кв. 2026** (=P×R) |
| T | **ДЕЛЬТА** (=P-S) |

**Колонки Q-T заполняются только для строк типа "Работа"** (для материалов матчинг по наименованию ненадёжен из-за артефактов парсинга).

Автофильтр включается на всю таблицу: `ws.auto_filter.ref = "A5:T{max_row}"`.

## Принципы построения формул

### 1. Одна управляющая ячейка
```
'Параметры_индексы'!$B$21
```
Все пересчёты на целевую дату ссылаются на неё. Меняешь индекс — пересчитывается всё.

### 2. Сходимость снизу вверх

Каждая итоговая ячейка должна быть **проверяемой**:
- Свод_ЛСР → даёт сумму = шапки ЛСР
- Сумма всех ЛСР = ИТОГО прямые работы в Себестоимость_итог
- НМЦК подрядчика без НДС = из обоснования НМЦК (с допуском 1 руб)

### 3. VLOOKUP для построчной аналитики

В Все_позиции колонка R (коэф. рыночности) делается через:
```excel
=IFERROR(VLOOKUP("01-01", 'Ключевые_работы'!$B$6:$G$30, 6, FALSE), 0.85)
```

Где:
- `"01-01"` — префикс кода ФЕР (из колонки H, обрезанный до 5 символов)
- `$B$6:$G$30` — таблица групп работ
- `6` — номер колонки коэф. рыночности (G от B = 6)
- `0.85` — fallback по умолчанию

### 4. Автоматическая покраска дельты

Условное форматирование на колонках:
- Положительная дельта (заработок) → светло-зелёная заливка + тёмно-зелёный шрифт
- Отрицательная дельта (убыток) → светло-красная заливка + тёмно-красный шрифт

В openpyxl через `PatternFill` и `Font` (без условного форматирования — оно сложнее настраивается).

## Запуск пересчёта формул

После создания/изменения Excel-файла **обязательно запусти**:

```bash
python3 /mnt/skills/public/xlsx/scripts/recalc.py smeta_aksonomia.xlsx 180
```

(`180` — таймаут в секундах). Это пересчитывает все формулы через LibreOffice и обновляет кэш значений. Без этого `data_only=True` в openpyxl вернёт `None` для всех формул.
