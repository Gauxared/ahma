# Индексы инфляции и базисный уровень цен

Российские сметы используют **трёхуровневую систему цен**, которая важна для корректного пересчёта стоимости на любую дату.

## Три уровня цен

| Уровень | Дата | Источник | Использование |
|---|---|---|---|
| **Базисный** | 4 кв. 2000 г. (01.01.2000) | ФЕР-2001 (ред. 2020 + изменения) | Цены, привязанные к сметной базе |
| **Текущий в ЛСР** | Обычно 4 кв. 2023 г. | Индекс Минстроя ~11.2-11.8 | Уровень, на котором сделана смета |
| **Целевой расчёта** | Любая будущая дата | Прогнозный индекс Минэкономразвития | Дата, на которую считаешь себестоимость |

## Где брать индексы

### Индекс перевода базис → текущий уровень ЛСР

Этот индекс находится **внутри самой сметы** — обычно в одной из колонок (часто значение типа `11.2`, `11.8`, `12.5`). Он отличается:
- По видам работ (земляные ≈ 11.2, дорожные ≈ 11.8, металлоконструкции ≈ 12.5)
- По регионам (есть региональные коэффициенты)

Индексы публикует Минстрой РФ ежеквартально в **письмах** (например, письмо Минстроя №19929-ИФ/09 от 30.10.2023). Их можно найти на сайте `https://minstroyrf.gov.ru` или в системах «Гранд-Смета», «Стройинформ».

### Прогнозный индекс к целевой дате

Если целевая дата — будущее, нужен **прогнозный индекс инфляции стройматериалов**:
- Источник: прогноз Минэкономразвития или СПДС
- Типичное значение для дорожного строительства: ~5,5% годовых (т.е. ~1,0046 в месяц)
- Найти можно в обосновании НМЦК или в письмах Минэкономразвития

### Совокупный индекс

```
Совокупный индекс = Индекс перевода × Прогнозный индекс
```

Это центральный параметр в Excel — обычно ячейка `Параметры_индексы!B21`. Все формулы пересчёта работают через неё.

## Извлечение индексов из обоснования НМЦК

В файле `03_Приложение_2-0_Обоснование_НМЦК.rtf` (или PDF) обычно есть таблица:

```
Индексы пересчёта сметной стоимости:
- Для общестроительных работ:           к 4 кв. 2023 — 11.2
- Для работ по устройству оснований:    к 4 кв. 2023 — 11.5
- Для асфальтобетонных работ:           к 4 кв. 2023 — 11.8
...

Прогнозный индекс на февраль 2026:      1.163741
Ежемесячный прогнозный индекс:          1.004472
```

В Python:

```python
import re

with open('obosnovanie_nmck.rtf') as f:
    text = f.read()

# Базовый индекс к текущей дате обоснования
m = re.search(r'Прогнозный индекс на \w+\s+\d{4}:\s*([\d.,]+)', text)
base_index = float(m.group(1).replace(',', '.')) if m else None

# Ежемесячный прогнозный
m = re.search(r'Ежемесячный прогнозный индекс:\s*([\d.,]+)', text)
monthly_index = float(m.group(1).replace(',', '.')) if m else None
```

## Расчёт совокупного индекса

```python
def calculate_combined_index(base_index, monthly_index, months_to_target):
    """
    base_index — индекс к дате обоснования НМЦК (например, к фев.2026)
    monthly_index — ежемесячный прогнозный (например, 1.0045)
    months_to_target — сколько месяцев до целевой даты
    """
    return base_index * (monthly_index ** months_to_target)

# Пример: обоснование на фев.2026, считаем на 2 кв. 2026 (т.е. май 2026)
# От фев до мая — 3 месяца
combined = calculate_combined_index(1.163741, 1.004472, 3)
# = 1.163741 * 1.004472^3 = 1.179423
```

## Структура листа "Параметры_индексы" в Excel

```
B5:  Дата обоснования НМЦК          [фев.2026]
B6:  Базовый индекс на дату НМЦК    [1.163741]
B7:  Ежемесячный прогнозный индекс  [1.004472]

B17: Целевой квартал расчёта        [2 кв. 2026]
B18: Месяцев от даты НМЦК           [3]                    ← УПРАВЛЯЮЩАЯ ЯЧЕЙКА
B19: Индекс перевода (4кв.2000→4кв.2023) [используется внутри ЛСР]

B21: =B6*B7^B18                                            ← СОВОКУПНЫЙ ИНДЕКС
     Совокупный индекс на 2 кв. 2026                       [1.179423]
```

**B18 — единственная управляющая ячейка**. Изменение её значения пересчитывает весь файл. По умолчанию это «расстояние в месяцах» от даты обоснования НМЦК до целевой даты.

## Все остальные листы Excel ссылаются на B21

Формулы пересчёта на 2 кв. 2026 во всех листах:
```
= [стоимость в текущих ценах 4кв.2023] * 'Параметры_индексы'!$B$21
```

Это позволяет одним движением (изменением B18) пересчитать весь файл на любую дату.

## Типичные значения индексов (для справки)

### Индексы перевода 4 кв. 2000 → 4 кв. 2023 г. (Минстрой)

| Вид работ | Индекс |
|---|---|
| Земляные работы | 11.2-11.5 |
| Бетонные работы | 11.4-11.8 |
| Дорожная одежда (асфальт) | 11.6-11.9 |
| Металлоконструкции | 12.0-12.8 |
| Гидроизоляция | 10.8-11.2 |
| Сборные ж/б изделия | 11.3-11.7 |
| Озеленение | 10.5-11.0 |

| Год | Тип строительства | Помесячный индекс |
|---|---|---|
| 2024-2025 | Дорожное | 1.0040 - 1.0050 |
| 2025-2026 | Дорожное | 1.0045 - 1.0055 |
| 2024-2025 | Жилое | 1.0050 - 1.0060 |

## Особенности и нюансы

### Региональные коэффициенты

Для разных регионов РФ есть **поправочные коэффициенты** к федеральным индексам:
- Москва, СПб: 1.05-1.10 (выше из-за стоимости труда)
- Центральная Россия: 0.95-1.00
- Северный Кавказ (включая Дагестан): 0.85-0.95
- Сибирь, Дальний Восток: 1.10-1.30

Если в смете не учтены — добавь поправку при расчёте на текущую дату.

### Индексы для НДС

С 1 января 2026 г. НДС в РФ — **22%** (с 20% поднимут). Учитывай при расчёте итогов с НДС.

```python
VAT_2025 = 0.20
VAT_2026 = 0.22
```

### Индексы для строительного контроля

Затраты заказчика (строительный контроль, авторский надзор) — индексируются **отдельно**, обычно по индексу СМР. Не включай в общий индекс материалов.
