# Рыночные цены строительных материалов в регионах России

Стратегия поиска рыночных цен зависит от региона реализации проекта. Не используй среднероссийские цены — они систематически завышены/занижены относительно реальных региональных.

## Алгоритм поиска

### Шаг 1. Идентифицируй регион

Из метаданных проекта (обоснование НМЦК, договор):
- Субъект РФ (республика, область, край)
- Город / район реализации
- Расстояние до ближайших промышленных центров

### Шаг 2. Определи региональную специфику

Регионы различаются по доступности материалов:

| Тип региона | Что дешевле | Что дороже |
|---|---|---|
| **Горные** (Дагестан, Кавказ, Алтай) | ПГС, щебень из карьеров | Битум, металлы (логистика) |
| **Нефтяные** (Татарстан, Башкирия, ХМАО) | Битум, бензин | Стройматериалы (низкая конкуренция) |
| **Промышленные** (Урал, Поволжье) | Металл, арматура, цемент | Импортные материалы |
| **Северные** (Якутия, Магадан) | Уголь | Всё привозное — наценка 30-50% |
| **Центральные** (Москва, Подмосковье) | Всё в среднем | Земля, труд (выше зарплаты) |

### Шаг 3. Для каждой категории материалов — отдельный поиск

Не ищи "стройматериалы в [регион]" — слишком общо. Делай прицельные запросы.

#### Бетон и растворы

```
"бетон [марка] цена куб [город] завод"
"раствор М150 цена [регион]"
```

Локальные заводы бетона есть в каждом регионе. Цена за М300-В25 в 2026 г.:
- Москва: 5 800-7 500 руб/м³
- Махачкала (Гамма-Бетон): 5 800-6 200 руб/м³
- Сибирь: 4 500-5 500 руб/м³

С W6 F-200 (гидротехнический) — надбавка 15-25%.

#### ПГС, песок, щебень

```
"ПГС природная цена м3 [город] карьер"
"щебень фракция 40-80 [регион] цена"
```

Дешевле всего там, где **карьеры рядом**: Дагестан, Карелия, Челябинская обл. В Москве/СПб — дороже из-за дальности.

#### Асфальтобетон

```
"асфальтобетон А16Вл цена тонна [регион] завод"
```

Обычно АБЗ при дорожных компаниях. Для **государственных дорожников** (Дагавтодор, Автодор-РТ) — цены ниже рыночных, т.к. свои заводы.

#### Битум

Битум — **самая рискованная позиция**. Он привозной из НПЗ (Уфа, Кстово, Самара, Тюмень, Омск). Цена в 2025-2026 г. на рынке:
- БНД 70/100: 50 000-60 000 руб/т
- БНД 60/90: 48 000-55 000 руб/т
- БНД 90/130: 52 000-58 000 руб/т

**В сметах ФЕР битум считается по индексу Минстроя**, который сильно отстаёт от реального рынка. Это типичная "чёрная дыра" в смете.

#### Металл и арматура

```
"арматура [диаметр] [класс] цена тонна [город]"
"металлоконструкции цена тонна [регион]"
```

Цены металла в РФ в 2025-2026 **упали** на 25-30% от пиков 2022-2023. Это даёт **заработок** на металле.

Типичные цены 2026 г.:
- Арматура А-III d≥12 мм: 65 000-85 000 руб/т
- Арматура А-I (гладкая): 60 000-75 000 руб/т
- Металлоконструкции: 80 000-120 000 руб/т

#### Сборные ж/б изделия

```
"звенья железобетонных труб цена м3 [регион]"
"бортовые камни БР цена [город]"
```

Локальные ж/б заводы. Местная цена обычно близка к смете (±5%).

#### Знаки, разметка, ограждения

```
"дорожный знак цена шт [регион]"
"парапетные ограждения ж/б цена куб"
```

Стандартные изделия — цена близка к смете. Особые (флуоресцентные, информационные) — выше сметы.

### Москва / Подмосковье
- **АБЗ «Маяк»**, **АБЗ-1**, **АБЗ «Капотня»** — асфальт
- **Моснеруд**, **СТМ-Неруд** — ПГС, песок, щебень

### СПб / Ленобласть

- **Бетонолит** — асфальт, бетон, нерудные

### Биржевые и общерос. цены битума
- **НГЕ** (`nge.ru`) — биржевые цены на нефтепродукты
- **Promportal**, **Pulscen** — площадки B2B
- Прямые прайсы заводов: Уфа (Башнефть), Кстово (Лукойл), Омск (Газпромнефть)

## Подход к битуму

Битум — главный риск. Стратегии минимизации:

1. **Закупка готового асфальтобетона** с АБЗ (битум уже в составе смеси)
2. **Долгосрочный контракт** с фиксированной ценой на сезон
3. **Закупка в межсезонье** (январь-март) — цены ниже на 10-15%
4. **Фасованный битум** в биг-бэгах вместо цистерн — для малых объёмов

В аналитике **обязательно отдельной строкой** показывай дельту по битуму.

## Погрешность рыночных цен

Учитывай:
- **Объём закупки**: на больших партиях (>500 т) скидка 5-15%
- **Сезонность**: лето дороже, зима дешевле
- **Логистика**: цена в карьере и на объекте — разница 20-50%
- **Договорные условия**: предоплата/отсрочка влияют на ±5%

Реалистичная погрешность рыночных цен — **±10-15%**. В аналитической справке это упоминай.
