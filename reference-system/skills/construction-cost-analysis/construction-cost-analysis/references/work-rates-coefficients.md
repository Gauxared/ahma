# Коэффициенты рыночности работ

В отличие от материалов, для работ нет "прайсов поставщиков". Поэтому используется концепция **коэффициента рыночности** — отношения реальной стоимости выполнения работы (собственными силами или субподрядом) к сметной стоимости.

## Логика

```
Коэффициент рыночности = Реальная стоимость / Сметная стоимость
```

- **Коэф. < 1** → подрядчик выполнит работу **дешевле сметы** → заработок
- **Коэф. = 1** → нулевая маржа на этой работе
- **Коэф. > 1** → подрядчик выполнит **дороже сметы** → убыток (редко)

Дельта по работе:
```
Дельта = Сметная стоимость × (1 − Коэф. рыночности)
```

## Откуда берётся коэффициент

Сметная стоимость работы по ФЕР включает:
- **ОТ** (оплата труда) — по нормативным тарифам Минстроя
- **ЭМ** (эксплуатация машин) — нормативные часовые ставки
- **М** (материалы расценки) — по среднефедеральным справочникам
- **НР** (накладные расходы) = 147% от ОТ
- **СП** (сметная прибыль) = 134% от ОТ

Реальная себестоимость подрядчика:
- **ОТ**: региональные зарплаты в строительстве часто на 15-30% ниже нормативных (особенно в регионах с низким уровнем жизни)
- **ЭМ**: своя техника окупается дешевле арендной, плюс региональные цены на ГСМ ниже
- **НР+СП**: реально подрядчик "сжимает" 50-70% от нормативных
- На субподряде маржа подрядчика — 5-15% от сметы

В сумме реальная себестоимость работы — 70-90% от сметной. **Это и есть коэффициент рыночности.**

## Зависимость от типа работ

### Земляные работы

Коэф. **0,80-0,85** — высокая маржа.

Почему:
- Своя техника (экскаваторы, бульдозеры, самосвалы) у большинства подрядчиков есть
- ГСМ в регионах дешевле нормативного
- Высокая доля ЭМ в расценке (50-60%), которую легко оптимизировать
- Простая технология — мало риска ошибки

Коды ФЕР: **01-01**, **01-02**.

### Дорожная одежда (асфальт, основания)

Коэф. **0,88-0,92** — средняя маржа.

Почему:
- Конкурентный рынок — много подрядчиков с асфальтовыми бригадами
- Высокая доля материалов в стоимости (асфальтобетон ~50% от стоимости работы)
- Цена готового асфальтобетона близка к сметной → меньше пространства для оптимизации

Коды ФЕР: **27-03**, **27-04**, **27-06**, **27-07**, **27-08**.

### Бетонные работы / устройство фундаментов

Коэф. **0,78-0,82** — высокая маржа.

Почему:
- Бетонные работы относительно простые
- Опалубка и арматура — у подрядчика свои
- НР+СП в расценках бетонных работ высокие → есть что "сжимать"

Коды ФЕР: **30-01**, **30-07**.

### Гидроизоляция

Коэф. **0,78** — высокая маржа.

Почему:
- Низкая трудоёмкость в сметной стоимости
- Простые материалы (битумная мастика, рулонные)
- Малая зарплатная составляющая

Коды ФЕР: **30-08**, **08-01**, **06-22**.

### Буровзрывные работы (БВР)

Коэф. **0,85-0,90** — узкая специализация.

Почему:
- Узкоспециализированный субподряд → меньше конкуренции → меньше маржи у генподрядчика
- Высокий риск (лицензии, безопасность)
- Дорогая взрывчатка и оборудование

Коды ФЕР: **03-01**, **03-02**.

### Обустройство дороги (знаки, разметка, ограждения)

Коэф. **0,82-0,85** — средняя маржа.

Коды ФЕР: **27-02**, **27-09**, **07-01**.

### Озеленение, рекультивация

Коэф. **0,70-0,75** — самая высокая маржа.

Почему:
- Низкая трудоёмкость и материалоёмкость в смете
- Высокие НР+СП в расценке
- Простые материалы (семена, грунт)

Коды ФЕР: **31-01**.

### Демонтаж

Коэф. **0,75-0,78** — высокая маржа.

Почему:
- Простые операции
- Полезный материал (металл) ещё и продаётся отдельно
- Высокие НР+СП в расценках

Коды ФЕР: **22-01**, **23-01** (с приставкой «Демонтаж»).

### Ремонт и восстановление

Коэф. **0,85** — средняя маржа.

Коды ФЕР: **53-21** (ФЕРр).

## Региональные поправки

Базовая таблица — для **Центральной России**. В регионах с особыми условиями применяй поправку:

| Регион | Поправка к коэф. | Логика |
|---|---:|---|
| Москва, СПб | +0,03 | Дороже труд → меньше маржи |
| Северный Кавказ (Дагестан и др.) | −0,02 | Дешевле труд → больше маржи |
| Сибирь (за пределами крупных городов) | −0,02 | Дешевле труд, но дорогая логистика — компенсируют друг друга, чуть в плюс |
| Дальний Восток, Якутия | +0,05 | Дорогая логистика → меньше маржи |
| Москва (по госконтрактам) | +0,05 | Высокий уровень контроля, мало пространства для "оптимизации" |

## Когда применять коэффициент

В Excel:
1. В листе `Ключевые_работы`: для каждой группы кодов в колонке **G** проставь коэф. из таблицы
2. В листе `Все_позиции`: для каждой строки типа "Работа" в колонке **R** через `VLOOKUP`:

```excel
=IFERROR(VLOOKUP("01-01", 'Ключевые_работы'!$B$6:$G$30, 6, FALSE), 0.85)
```

Где `01-01` — префикс кода ФЕР из колонки H, обрезанный до 5 символов.

3. Дельта рассчитывается автоматически через формулы:
```excel
S = P × R   # рыночная стоимость
T = P − S   # дельта (заработок)
```

## Тонкая настройка под подрядчика

Базовая таблица — это **отраслевые средние**. У конкретного подрядчика реальные коэффициенты могут отличаться:

- **Свой АБЗ** → коэф. для 27-06 не 0,92 а 0,82 (сам производит асфальт)
- **Свой парк техники** → коэф. для 01-01 не 0,82 а 0,75 (своя техника окупается)
- **Опыт в БВР** → коэф. для 03-02 не 0,88 а 0,80
- **Привлечение мигрантов** → коэф. везде −0,05 (дешевле труд)
- **Аренда всего у субподряда** → коэф. везде +0,05 (меньше маржи)

В аналитической справке упомяни: "Коэф. — отраслевые средние, на листе Ключевые_работы можно скорректировать под опыт подрядчика".

## Погрешность коэффициентов

Реалистичная погрешность — **±5-7%** в зависимости от группы.

Самые **точные** коэф.:
- Дорожная одежда (большая выборка статистики)
- Земляные работы

Самые **спорные**:
- БВР (зависит от лицензий подрядчика)
- Озеленение (мало данных)
- Спецработы
